# BentoPDF

Deployment preset. Image digests and registry platforms checked; non-root runtime acceptance pending.

Browser-based PDF tools in a self-hosted web interface.

## Requirements

- Uses the current non-root image on port 8080; the upstream Compose port 80 is outdated.
- PDF processing runs in the browser; review browser memory limits for large files.
