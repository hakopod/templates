# NocoDB

Deployment preset. Image digest and amd64/arm64 platforms checked; local container started as UID 1000 on arm64 and /api/v1/health and / returned 200.

Self-hosted spreadsheet-style interface over databases, using SQLite on a persistent volume for its metadata.

## Requirements

- Persistent block or local storage for /usr/app/data, which holds the SQLite metadata database and uploaded attachments
- Complete the first super-admin sign-up before sharing the URL
- The JWT secret signs sessions; keep it stable and back it up with the data volume
- SQLite suits small teams. For heavy use, point NocoDB at PostgreSQL with NC_DB; that is not part of this preset

## Credentials

- jwt-secret: generated by Hakopod, passed as NC_AUTH_JWT_SECRET.

## Ordinary configuration

Use the catalog options described in the root README.
